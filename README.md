# بصيرة — عرض تقديمي تفاعلي

عرض سينمائي عربي مبني على مشروع React + TypeScript + Vite الحالي. تمت تعبئة المشاهد الخمسة عشر بالمحتوى المعتمد والصور الفعلية للمنتج، مع التنقل اليدوي بين خطوات الكشف. يحافظ العرض على الكحلي والتركوازي والذهبي والعاجي، وعلى مسرح 16:9 مرجعه 1920×1080.

للمشاركة كرابط عام عبر GitHub، اتبع [دليل GitHub Pages](GITHUB_PAGES.md). ملف النشر التلقائي جاهز في `.github/workflows/deploy.yml`؛ يُفعّل بعد رفع المشروع وتحديد GitHub Actions في إعدادات Pages.

## التشغيل

افتح Terminal داخل مجلد المشروع. يحتاج تثبيت الحزم إلى Node.js 22.12 أو أحدث وnpm:

```powershell
npm install
npm run dev
```

افتح الرابط المحلي الذي يعرضه Vite. يمكنك أيضًا النقر المزدوج على `عرض-بصيرة.cmd` لتشغيل العرض وفتح المتصفح. تبدأ التجربة بشاشة داكنة مقصودة؛ اضغط السهم الأيمن لكشف الصورة، ثم تابع لإظهار السؤالين.

لإنشاء نسخة الإنتاج ومعاينتها:

```powershell
npm run build
npm run preview
```

تُكتب ملفات الإنتاج في `dist/`. اعرضها عبر خادم محلي؛ فتح `dist/index.html` مباشرة لا يكفي. بعد تثبيت الحزم يعمل العرض محليًا دون اتصال بالإنترنت، وجميع الصور محلية دون CDN أو خطوط من Google Fonts.

```powershell
npm run lint
npm test
npm run test:scenes
npm run format:check
```

`npm run format` ينسق ملفات المصدر. تغطي الاختبارات التنقل وإعادة المشهد وحدود الخطوات ووجهي PageFlip، إضافة إلى سلامة نسخ الصور وأبعادها الأصلية. يفحص `test:scenes` مكونات المشاهد الخمسة عشر بجميع خطواتها الـ76 واستخدام الأصول الاثني عشر دون فتح متصفح. نتائج التحقق وحدود المراجعة البصرية في [QA.md](QA.md).

## التحكم أثناء العرض

| المفتاح                     | الوظيفة                                      |
| --------------------------- | -------------------------------------------- |
| السهم الأيمن `→` أو `Space` | الخطوة التالية، ثم المشهد التالي             |
| السهم الأيسر `←`            | الخطوة السابقة، ثم آخر خطوة في المشهد السابق |
| `F`                         | تبديل ملء الشاشة                             |
| `Escape`                    | الخروج من ملء الشاشة                         |
| `Home`                      | بداية المشهد الأول                           |
| `End`                       | بداية المشهد الأخير                          |
| `R`                         | إعادة المشهد الحالي إلى الخطوة صفر           |

تظهر أدوات المقدم عند تحريك المؤشر أسفل الشاشة وتختفي بعد فترة قصيرة. تعرض السابق والتالي ورقم المشهد والخطوة وملء الشاشة وإعادة المشهد. الخط الذهبي السفلي يعكس تقدم المشاهد، وليس الوقت. لا يوجد تشغيل تلقائي زمني.

## الصور الفعلية

اكتُشفت **12 صورة** داخل `ui/`: عشر واجهات، الشعار `logo.jpeg`، وصورة `qaytbay-sabil.jpg`. صُنفت الواجهات بالفحص البصري، وليس بأسماء WhatsApp. نُسخت الصور دون تغيير إلى `public/assets/ui/`، وبقيت الأسماء والملفات الأصلية محفوظة في `ui/`.

خريطة الصور المركزية هي `src/data/uiAssets.ts`. تحتوي مفاتيح دلالية مثل `home` و`map` و`quiz` و`competition`، مع اسم الملف الفعلي ووصفه وأبعاده. يستخدم كل مشهد هذه الخريطة؛ لا تضف مسارات صور متفرقة داخله. التقرير التفصيلي في [ASSET_REPORT.md](ASSET_REPORT.md)، والجرد ومعاينة جميع الملفات في `previews/asset-inventory.json` و`previews/asset-contact-sheet.jpg`.

```tsx
import { UiImage } from '../components/ui/UiImage';
import { uiAssets } from '../data/uiAssets';

<UiImage asset={uiAssets.map} fit="contain" />;
```

`UiImage` يحافظ على أبعاد الصورة ويدعم `contain` و`cover` و`loading="lazy"` و`alt` و`fallback` و`className` و`style`. تظهر حالة تحميل أثناء تجهيز الصورة؛ عند الفشل يُزال عنصر الصورة وتظهر رسالة أو البديل الممرر دون أيقونة صورة مكسورة. استخدم `contain` للواجهات التي تحتوي تفاصيل مهمة.

الشعار الأصلي مربع 1254×1254، ويظهر بنسبته وألوانه كما ورد. صورة سبيل قايتباي عمودية 3262×4893؛ تُعرض داخل إطار يحفظ المعلم، ولا تستبدلها بصورة قبة الصخرة. جميع الواجهات بقياس 1672×941. صور قبة الصخرة موجودة ضمن واجهات استعراض المنتج، بينما الافتتاحية مرتبطة بسبيل قايتباي فقط.

عند استبدال صورة أو إضافة ملف PNG أو JPG أو JPEG أو WebP، حدّث `sourceFile` وأبعادها في الخريطة واحتفظ بالامتداد الحقيقي. تُشفّر أسماء الملفات عند بناء المسار، بما فيها المسافات والأقواس. حدّث الجرد إذا تغيرت الصور، وأعد البناء لنسخة الإنتاج. لا توجد صور مطلوبة مفقودة في النسخة الحالية.

## تحميل الصور والأداء

تُجهز صورة الافتتاح والشعار عند البداية، وتُحمّل أصول المشهد الحالي والمشاهد القريبة عبر `sceneAssetKeys`. تبقى صور المشاهد البعيدة عند الطلب. التخزين المؤقت في المتصفح يسمح بإعادة استخدام الملف نفسه بين المشاهد، دون تحميل نسخ مختلفة منه. فشل صورة لا يمنع بدء العرض أو التنقل.

لا تُعرض كل الواجهات دفعة واحدة؛ لكل مشهد صورة رئيسية ومواد داعمة تظهر حسب الخطوة. لوحة الجرد في `previews/` مخصصة للمراجعة وليست جزءًا من العرض.

## الهيكل والتعديل

```text
ui/                         الصور الأصلية المستلمة
public/assets/ui/           النسخ المحلية المستخدمة في العرض
public/docs/                وثائق أصلية اختيارية
previews/                   جرد الصور ومعاينات المراجعة
src/components/
  presentation/             المسرح ومحرك التنقل وأدوات المقدم
  animations/               الكشف والخط والعداد وPageFlip
  ui/                       UiImage والشعار وعناصر الهوية
  aqsa/                     عناصر المعالم والخريطة
src/scenes/                 محتوى المشاهد 01–15
src/hooks/                  التنقل وملء الشاشة وتحميل الصور
src/config/                 ترتيب المشاهد والخطوات والهوية
src/data/                   uiAssets والميزانية والفريق والمراحل
src/styles/                 التخطيط والطباعة والحركة
tests/                      اختبارات المحرك وPageFlip والأصول
```

يستقبل كل مشهد `SceneProps`: `id` و`title` و`number` و`totalSteps` و`currentStep` و`onStepChange`. تبدأ أرقام الخطوات من صفر؛ `totalSteps: 4` تعني 0 و1 و2 و3. عند إضافة خطوة حدّث العدد في الإعدادات وشروط ظهور المحتوى.

```tsx
<>
  {currentStep >= 1 && <p>يظهر من الخطوة الأولى ويستمر بعدها</p>}
  {currentStep === 2 && <p>يظهر في الخطوة الثانية فقط</p>}
</>
```

يبقى محرك العرض مستقلًا عن محتوى المشاهد. الرجوع وإعادة المشهد يعيدان الحالة البصرية بحسب `currentStep`.

## الهوية والحركة

المستند عربي `lang="ar"` و`dir="rtl"`. يتناسب المسرح مع مساحة الشاشة دون تمديد أو تمرير، وقد تظهر مساحة حوله عند اختلاف نسبة الشاشة عن 16:9. ملء الشاشة يبدأ من زر التحكم أو `F` بتفاعل المستخدم.

Framer Motion هو أساس الانتقالات، وGSAP متاح للحركات المركبة. تشمل المكونات القابلة لإعادة الاستخدام `AnimatedText` و`CinematicReveal` و`GoldLineReveal` و`ImageMaskReveal` و`Counter`. يكشف النص العربي بالكلمات للحفاظ على اتصال الحروف، وتراعي الحركات إعداد تقليل الحركة.

يستخدم **المشهد 11 فقط** `PageFlip` للتحول من صفحة تقليدية إلى واجهة بصيرة. التنفيذ المحلي باستخدام CSS 3D بوجهين وتحكم `flipped`؛ مكتبة `page-flip` المثبتة بقيت ضمن المشروع. لا يطبق تقليب الصفحات بين جميع المشاهد.

حزم `three` و`@react-three/fiber` و`@react-three/drei` مثبتة للاستخدام المستقبلي. العرض الحالي يعرض صور النموذج الأولي ولا يشغّل محاكاة ثلاثية الأبعاد. أرقام نقاط المسابقة والعدادات أمثلة توضيحية داخل العرض.

## البيانات المعتمدة والصوت

الميزانية في `src/data/budget.ts`: تأسيس 6,000 ₪ وتشغيل حتى 300 ₪ شهريًا، والعمل تطوعي دون أجور الفريق. أسماء الفريق في `src/data/team.ts` دون مناصب غير مؤكدة. تعرض خطة التنفيذ جمع المعلومات الموثوقة، ثم النماذج ثلاثية الأبعاد، ثم المحاكاة والتحديات، ثم الاختبار والنشر والتطوير المستمر.

الصوت معطّل افتراضيًا. يمكن إضافة ملفات `ambience.mp3` و`click.mp3` و`transition.mp3` إلى `public/assets/audio/` واستخدام `createPresentationAudio()` من `src/utils/audio.ts` عند اعتماد التفعيل. غياب الصوت أو رفض المتصفح تشغيله لا يعطل العرض. الوثائق داخل `public/docs/` اختيارية ولا تتطلبها التجربة الحالية.
