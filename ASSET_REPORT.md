# تقرير أصول بصيرة وتحديث الشرائح

تاريخ التحديث: **9 أكتوبر 2026**.

أصبح العرض الحالي **17 شريحة كاملة المحتوى**، بعد إضافة شريحة المعالم غير المعروفة بين المشكلة والتعريف ببصيرة. يكفي **16 ضغطة على «التالي»** للوصول من الأولى إلى الأخيرة؛ الحركات قصيرة وتعمل تلقائيًا، ولا توجد خطوات كشف إلزامية أو شريحة فارغة تتطلب نقرة. حُفظ المحتوى المعتمد للمشكلة والحل والأهداف والتكلفة والفريق وخطة التنفيذ والرؤية.

## الصور المعتمدة

يوجد **25 أصلًا داخل `ui/`**: **15 واجهة للمنظومة**، الشعار، صورة سبيل قايتباي الافتتاحية، و**8 صور معالم** داخل `ui/معالم غير معروفة/`. بقيت ملفات الأصول وأسماؤها دون تعديل. تكتفي التسميات المعروضة بتصحيح الكتابة إلى «قبة يوسف آغا» و«مسطبة الورود / الياسمينة»، مع الحفاظ على اسمي الملفين الأصليين.

تجمع [خريطة الأصول](src/data/uiAssets.ts) اسم الأصل `sourceFile` واسم النسخة المعروضة `servedFile` وأبعاد كل منهما. يوجد الجرد التفصيلي للحجوم والأبعاد وبصمات SHA-256 في [asset-inventory.json](previews/asset-inventory.json). [لوحة الصور](previews/asset-contact-sheet.jpg) مخصصة لمراجعة الأصول، ولا تمثل تصويرًا للعرض الجاري في المتصفح.

## الحجم والنسب

## النسخة المحمولة دون إنترنت

يجهز `scripts/build-offline.mjs` ملف **`dist/downloads/Basira-Offline.html`** بعد البناء. يتضمن الملف JavaScript وCSS وجميع صور السجل الـ25 ببياناتها داخل HTML واحد، دون روابط صور أو مكتبات أو خطوط خارجية. يحافظ الملف على النص العربي وRTL وأدوات العرض، ويمكن فتحه مباشرة من القرص في متصفح حديث دون تشغيل Node.js أو خادم محلي.

يظهر زر **«تحميل العرض»** في أدوات النسخة المستضافة، ويحمّل الملف الكامل. يختفي زر التنزيل داخل النسخة المحمولة نفسها. تُجهّز نسخة واضحة للمشاركة باسم **`بصيرة-بدون-إنترنت.html`** على سطح المكتب؛ يمكن إرسال هذا الملف الواحد للأصدقاء. يحتاج تحديث النسخة المتاحة عبر رابط GitHub Pages إلى رفع الملفات المعدلة وإعادة النشر.

يتحقق `npm run test:offline` من الملف الناتج: جميع الصور مضمنة ومطابقة، لا توجد ملفات JavaScript إضافية، ولا صور أو أنماط أو خطوط مطلوبة من الخارج. يزيد تضمين Base64 حجم ملف HTML عن مجموع ملفات الصور المحسنة؛ الأرقام أعلاه تخص الصور فقط.
