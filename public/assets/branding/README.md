# شعار بصيرة

ضع ملف الشعار الحقيقي هنا باسم `logo.png`، ويُفضّل PNG شفافًا ذا دقة جيدة وقابلية قراءة على الخلفية الداكنة. يظهر في شاشة التحميل والمشهد الثالث عند توفره. عند غيابه يظهر بديل بصري يحمل اسم بصيرة.

لم يُنشأ ملف صورة وهمي. بعد إضافة الشعار، حدّث الصفحة في التطوير أو أعد `npm run build` لنسخة الإنتاج.
