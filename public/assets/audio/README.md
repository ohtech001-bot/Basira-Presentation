# الصوت الاختياري

الصوت معطّل افتراضيًا. يمكن إضافة ملفات محلية مرخّصة بالأسماء التالية:

- `ambience.mp3`: أجواء خلفية منخفضة الصوت وقابلة للتكرار.
- `click.mp3`: صوت تفاعل قصير.
- `transition.mp3`: صوت انتقال خفيف.

الأداة `src/utils/audio.ts` تدعم التفعيل الصريح وتغيير مستوى الصوت والإيقاف والتنظيف. لا يبدأ الصوت تلقائيًا؛ يُفعّل فقط بعد اختيار المستخدم داخل تفاعل مباشر. الملفات المفقودة أو منع التشغيل من المتصفح لا يعطّلان العرض. لا توجد ملفات صوت وهمية.
