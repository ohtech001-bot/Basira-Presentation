# صور المنظومة والهوية

هذا المجلد يحتوي نسخ العرض من **17 أصلًا** داخل `ui/`: 15 واجهة للمنظومة، الشعار، والصورة الفوتوغرافية لسبيل قايتباي.

الأصول الأصلية محفوظة دون تعديل في `ui/`. تحتوي نسخ العرض على 11 ملف WebP محسنًا و6 ملفات JPEG محفوظة كما وردت، تشمل الشعار الأصلي. انخفض حجم الصور المعروضة من 71.38 MB إلى 7.77 MB بنسبة 89.11%، دون قص أو إعادة تصميم. الشعار `logo.jpeg` مطابق للأصل byte-for-byte وبأبعاده وألوانه الأصلية.

تجمع `src/data/uiAssets.ts` اسم الأصل `sourceFile`، واسم النسخة المعروضة `servedFile`، وأبعاد كل منهما. تستخدم الشرائح هذه الخريطة ومكوّن `UiImage`، مع `contain` لحماية تفاصيل الواجهات ونسبها.

لتحديث الصور، عدّل الأصول وخريطة أسمائها في `scripts/inspect_assets.py`، ثم شغّل البرنامج باستخدام Python وPillow، وحدّث سجل `uiAssets` بالأبعاد الناتجة. يجهّز البرنامج نسخ العرض والجرد ولوحة المراجعة، ويزيل الصور المعروضة القديمة التي استبدلتها النسخ الجديدة؛ لا يعدّل ملفات `ui`.

الجرد في `previews/asset-inventory.json` يسجل أبعاد الأصول والنسخ وحجومها وبصمات SHA-256. راجع `ASSET_REPORT.md` لمعرفة الاستخدام الفعلي لكل صورة ونتائج التحقق النهائي.
