# صور المنتج والهوية

هذا المجلد يحتوي النسخ المستخدمة في العرض من الملفات الأصلية داخل `ui/`: عشر واجهات، `logo.jpeg`، و`qaytbay-sabil.jpg`.

احتُفظ بالأسماء والامتدادات والأبعاد وبايتات الملفات الأصلية. تستخدم المشاهد الخريطة المركزية في `src/data/uiAssets.ts` ومكوّن `UiImage`؛ لا تضف مسارات مكررة داخل المشاهد.

عند استبدال ملف، حدّث الأصل والنسخة المحلية والخريطة وأبعاد الصورة والجرد في `previews/asset-inventory.json`. ثم أعد البناء والتحقق من سلامة الأصول. الواجهات تحتاج `contain` لحماية تفاصيلها من القص، والشعار يحافظ على نسبته وألوانه الأصلية.

راجع `ASSET_REPORT.md` في جذر المشروع لمعرفة وظيفة كل ملف والمشاهد التي تستخدمه.
