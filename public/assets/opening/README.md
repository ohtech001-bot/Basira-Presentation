# صورة افتتاح العرض

ضع الصورة الأصلية هنا باسم `opening-landmark.jpg`. يستخدم المشهدان الأول والثاني الملف نفسه. يُفضّل مقاس أفقي قريب من 1920×1080، مع ترك المعلم الرئيسي في مساحة آمنة لأن الحركة قد تقص بعض الأطراف.

لم تُختر صورة أو إجابة غير معتمدة. إذا كان الملف غير موجود تظهر خلفية سينمائية بديلة، ويظل نص «اسم المعلم» في المشهد الثاني مؤقتًا إلى اعتماد الاسم.
