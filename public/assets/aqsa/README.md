# صور ومعالم المسجد الأقصى المبارك

احفظ هنا الصور والخرائط الموثوقة والمعتمدة. أضف تعريفاتها في `src/data/landmarks.ts` بعد التحقق من الاسم والموقع والمصدر وحقوق الاستخدام. إحداثيات العلامات نسبية من 0 إلى 100 وفق الخريطة المستخدمة.

المصفوفة المبدئية فارغة عمدًا. لا توجد أسماء معالم أو مواقع مختلقة، ولا يُحمّل نموذج ثلاثي الأبعاد في العرض الحالي.
